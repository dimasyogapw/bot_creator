# Bot Creator

Aplikasi web pribadi untuk membuat dan mengelola chatbot: persona, knowledge, memory, skills, lalu publikasi ke link publik, widget, Telegram, dan WhatsApp.

## Mulai dari sini
1. `docs/SETUP.md`: siapkan akun, kunci, dan tempat kerja.
2. `prompts/PLAYBOOK.md`: prompt Claude Code per fase.
3. `docs/PROGRESS.md`: status pengerjaan.

## Dokumen
- `CLAUDE.md`: aturan kerja untuk Claude Code
- `docs/PRD.md`: apa yang dibangun dan yang tidak
- `docs/ARCHITECTURE.md`: stack, model data, alur pesan, keamanan
- `docs/UI.md`: design brief
- `evals/cases.example.jsonl`: contoh test case

Stack: Next.js, Supabase, SumoPod (OpenAI-compatible), Vercel (mulai fase 5).
